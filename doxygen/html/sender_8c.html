Detailed Description

A UDP sender program.

This contains the code for the sender using the UDP file transfer protocol. The main function parses the command line arguments and then calls the rsend function to send the file.

void rsend ( char * hostname,
unsigned short int hostUDPport,
char * filename,

Sends the first bytesToTransfer bytes of the file indicated by filename to the receiver at hostname:hostUDPport.

This function sends the file using the UDP (SOCK_DGRAM) file transfer protocol. The bytes should be transferred correctly and efficiently, even if the network drops or reorders packets. See rrecv for the counterpart function.

Parameters
hostnameThe name of the receiver host.
hostUDPportThe port number on the receiver host.
filenameThe name of the file to transfer.
bytesToTransferThe number of bytes to transfer.
